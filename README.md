# walkie-e2e-github-reviewers

This is a **Walkie E2E test repository** for Walkie request 38167 (GitHub reviewer mentions).

- Purpose: pull requests in this repository request reviewers so that Walkie's GitHub webhook handling
  (review requests, re-requests, team requests, redeliveries) can be verified end to end in an isolated place.
- It contains **no secrets** and no product code.
- Pull requests, review requests and comments here are test traffic.
- The repository **will be archived** after the test.

Maintained by Andy Ai (OneCiel).
